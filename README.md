# Bruitenkor ! 
- - - 
## Sound machine for STM32F4 Discovery kit
- - -

Funny drum machine controlled by PC usb keyboard plugged in the board.
The STM32F4 Discovery kit acts as a USB host.


- - - - 

Configurable project with ioc and BSP files.

C++ compatible.
